## 🎯 三、 個股核心看點與戰略評語

1. 🟩 **NVIDIA (NVDA)**：AI 算力絕對龍頭，毛利率 71%、淨利率 55.6% 冠絕全球，F-Score 9/9 滿分。
2. 🔍 **Alphabet / Google (GOOG)**：搜尋壟斷 + Cloud 利潤暴增 + 全美股第一大現金流 ($1,647 億美元 OCF)，P/E 30.2x 具極佳防禦性。
3. 🦾 **Arm Holdings (ARM)**：全球 99% 手機 CPU IP 壟斷者，毛利率高達 **95.2%** 天花板。受惠於 v9 架構與 AI 算力 CSS 客製晶片升級，版稅收益暴增。
4. ⚡ **Marvell (MRVL)**：客製化 AI ASIC 晶片與 PAM4 光電轉接 DSP 雙雄，直接對接 AWS、Google 與 Meta 客製化晶片訂單。
5. 👁️ **Coherent (COHR)**：AI 資料中心 800G / 1.6T **光收發模組 (Optical Transceivers)** 與碳化矽 (SiC) 關鍵獨占巨頭。
6. ⚡ **Tesla (TSLA)**：FSD v13、Cybercab Robotaxi 與 Megapack 儲能具備極高的 AI 選擇權溢價。
7. 🔷 **Intel (INTC)**：處於 x86 轉型與 18A/14A 晶圓代工 (Foundry) 的重資本轉型期，短期自由現金流受建廠支出壓縮，屬長線轉型對賭標的。
8. 📶 **Nokia (NOK)**：低 P/E (24.0x) 的 5G/6G 電信網絡基礎設施與專利權收費防禦股。
